# Blog brief writing
Format reference: blog/briefs/ and blueprints/blog.md. Apply `gw-brand-guidelines`.

## Inputs (Brennan, Nov 24)
Topics come from `blog-keyword-research`. Semrush is the only keyword source. All or almost all posts come from Semrush keywords plus GW Video Research, a main input for every brief, not an add-on. Without both, the brief is not ready. PAA is not the topic source; it may support question wording and AEO answers (H2s, FAQs). The writer can only add something new if the brief names it.

## Brief template (full text: blueprints/blog.md)
Required: Title (= site H1, question word for word); slug (lowercase, hyphenated, unique); 2 alt SEO titles; target keyword + `Semrush` tag; volume/KD or `n/a`; secondary keywords; intent and stage (SERP); industry (HVAC, roofing, B2B lead; fencing max 3/week, team/industry-mix.md); SERP study (what ranks, page type, mixed-intent format or round-up backdoor; every subtopic); main point (one sentence; outline never contradicts it; plain words, no jargon; Nov 6 coherence); research inputs named in Sources (Semrush/SERP + Video Research notes: any video, any trade, adapt to direct mail, library first); information gain (required one sentence vs the top three); format (post, list, best-X, comparison, review; word range is a guide only [JUDGMENT]); piece type (standard, "<competitor> alternative for <industry>", three-way listicle, or refresh for ranks ~8-20: name the missing section and stale facts; keep what ranks); E-E-A-T plan (TL;DR, TOC, approved numbers, what worked and didn't); cluster (money page + siblings); direct answer draft (40-60 words, consensus first, US/state scope); outline (H2s as related questions, PAA wording allowed as support, one-line answer-first intent; FAQ 3-5; closing + CTA; off-mail topics still recommend custom direct mail); optional `gw-lead-magnets` upgrade (Brennan approval); sources (`[S:ID]` V/S only + URL; `[NEED: ...]`; start `gw-fact-check` claim table); internal links + /book-demo (A/B log); rules reminders (`gw-content-rules`, `gw-claims-guardrails`; no prices; nothing invented); Notion: Excerpt, SEO Title, Meta Description (140-160 chars, keyword, benefit first, reason to click, unique), Publish At (9:00 AM New York, correct offset).

## Steps
1. Pull the keyword from `blog-keyword-research` and Video Research notes from `video-research`.
2. Fill the template. Never invent numbers: write "not on file".
3. Save to blog/briefs/<date>/<nn>-<slug>.md; hand to the Blog Copywriter, then `gw-longform-editor`.

## Learning loop
Weekly (blueprints/blog.md loop): compare briefs of top and bottom 20% posts; log what the winners' briefs had. Related: `gw-lead-generation`, `longform-seo-article`.
