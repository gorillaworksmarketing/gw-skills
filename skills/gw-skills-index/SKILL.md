# GW skills index
**Standing rules:** (1) Check this index at session start; load matching skills. (2) New training files: merge into the matching skill and blueprint at session start (blueprints/skills-index.md). (3) Bots never send, post, file or pay; Brennan approves. (4) Depth file pointers: blueprints/skills-index.md. (5) Each SKILL.md ≤3,500 characters; overflow to blueprints/. (6) Source of truth: gorillaworksmarketing/gw-skills; GW Skill Builder pushes changes.

## Shared (all bots)
- `api-access-guide`: before any GW API or connector call.
- `api-issue-handling`: any API error: classify, handle or report; never leave silent (detail: blueprints/skills-index.md).
- `notion-shared-rate-limit`: any Notion read or write; shared Ember limit (detail: blueprints/skills-index.md).
- `gw-brand-guidelines`: every bot, every piece (what it covers: blueprints/skills-index.md).
- `gw-content-rules`: any GW copy; mandatory rules and the AEO/FAQ pattern.
- `gw-claims-guardrails`: any claim, price, testimonial, or competitor mention.

- `gw-lead-generation`: anything meant to generate leads or demos.

- `gw-skills-index`: this index.
