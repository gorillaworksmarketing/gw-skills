# GW skills index
**Standing rules:** (1) Check this index at session start; load matching skills. (2) Merge new training files into the matching skill and blueprint at session start. (3) Bots never send, post, file or pay; Brennan approves. (4) Depth file pointers: blueprints/skills-index.md. (5) Each SKILL.md ≤3,500 characters; overflow to blueprints/. (6) Source of truth: gorillaworksmarketing/gw-skills; GW Skill Builder pushes changes.
